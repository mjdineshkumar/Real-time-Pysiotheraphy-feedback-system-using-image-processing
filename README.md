# Real-time-Pysiotheraphy-feedback-system-using-image-processing
The project aims to make physiotherapy more accessible, affordable, and effective for hospitals, rehabilitation centers, physiotherapy clinics and home based care.
Real time Physiotherapy Feedback System Using AI Based Pose Estimation is an Edge AI rehabilitation solution built with Raspberry Pi 5, Python, OpenCV, and MediaPipe. It monitors body posture in real time, calculates joint angles, provides instant visual and voice feedback, counts repetitions, supports affordable and contactless physiotherapy.
Widely used in the Applications of Physiotherapy Clinics, Hospitals, Rehabilitation Centers, Home Physiotherapy, Stroke Rehabilitation, Sports Injury Recovery, Orthopedic Rehabilitation, Elderly Care, Tele-rehabilitation.
This model work by Capture live video through the camera, Detect 33 body landmarks using MediaPipe Pose, Calculate joint angles (shoulder, elbow, hip, knee, etc.), Compare the detected posture with reference exercise positions, Count repetitions automatically, Provide real time voice and visual feedback and Save exercise performance for future analysis.
Future Enhancements for this model are Therapist Dashboard, Cloud-Based Patient Monitoring, Mobile Application, AI Based Personalized Exercise Recommendations, Multilanguage Voice Guidance,, Progress Analytics and Reporting.
